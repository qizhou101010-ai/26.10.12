# 每类数据怎么核查，以及实测结果

## 审核一行的顺序

1. **格式检查**（程序）：漏填、字符类型、字符数、经纬度格式、小数位、合理范围、书名号、日期格式。
2. **找资料**（程序）：按《资料名》在资料库里找文件。先精确匹配文件名或首行标题（忽略书名号、全半角括号），再模糊匹配（相似度 ≥ 0.8）。
3. **核对内容**（程序），只看资料里讲该对象的段落：

| 数据 | 怎么查 | 什么时候转人工（“不确定”） |
|---|---|---|
| 数字 | 找“关键词 + 数字 + 单位”。关键词先用数据类型本身（去掉年份），找不到再用同义词（高度→海拔/高程，长度→全长，深度→水深……）。单位自动换算（米/千米，平方米/平方公里/公顷/亩，人/万人，元/万元/亿元，吨/万吨）。“海拔900米以下”这类后面跟“以下、以上、之间、至”的范围界线不算。 | 找不到；找到多个不同的候选值 |
| 统计年份 | 数据类型写了年份（如“2021年末常住人口”）而资料那句话的年份不同 → 报“统计年份不符”（需复核） | — |
| 坐标 | 提取原文的“东经……北纬……”，换算成十进制度比较，相差 ≤ 1′ 算一致；能识别经纬度写反 | 找不到；有多个不同坐标 |
| 名称 | 资料里是否出现这个名称 | 没出现（可能是别名） |
| 描述性文字 | 整句在原文出现 → 支持；否则拆成短语（按标点和“和、及、与”），每个短语要在某一句里连续相同至少 80%（避免把“东坡陡峭”当成原文的“西坡陡峭”） | 有短语找不到；或找到了但上下文像在引用 / 辟谣（网传、谣言、辟谣、误区、事实查核、所谓、据说、实际上、问号、引号等） |

   **引错出处**：内容在引用的资料里找不到时，程序会到资料库的其他资料里再查一遍；别的资料能证明它，就报“出处可能引错”，建议正确的资料名并给出该资料的发布日期（需复核，不自动改）。

4. **核对来源日期**（程序）：在资料开头 300 字里找“XXXX年X月(X日)”或“XXXX-XX(-XX)”；有多个日期时优先“出版、发布、印发、公布、编、成文”附近的。只填到月时年月一致即可。填写的日期写成“2018-6”“2018/6”“2018年6月”等时，先统一成 2018-06 再比较，并报格式错误、自动改成标准写法。
5. **程序拿不准时**：默认转人工复核，附相关原文；开了模型则交给模型，模型给出的原文证据必须能在资料里逐字找到，否则也转人工；模型调用失败自动转人工。
6. **修正**：程序有把握、给出了建议值、且不是描述性内容时才自动改（黄色）；其余只标出（橙色）。描述性内容即使有错也不自动改写。

## 实测结果

### 模拟数据（虚构的青石山、白云岭，纯程序模式）

| 埋入的错误 | 结果 |
|---|---|
| 高度 120（资料 1203 米）、768（资料 876 米） | 抓到并自动改正 |
| 来源日期 2019-06（资料 2018 年 6 月） | 抓到并自动改正 |
| 经纬度写反 | 抓到并自动改正 |
| 十进制度坐标（与原文度分秒等价） | 正确判为一致 |
| 地形走向、坡向写反 | 未误判通过，转人工 |
| 植被多写“竹林” | 转人工，并指出“竹林”找不到 |
| 引错资料 | 转人工，并指出资料里找不到这些说法 |
| 2017 年数据冒充 2021 年 | 报“统计年份不符” |

### 公开数据集 CHEF（中文新闻事实核查，测的只是“描述性文字能否被证明”）

| 方法 | 自动判定比例 | 准确率 |
|---|---|---|
| 直接问 DeepSeek | 100% | 74.7%（抽样 150 条） |
| 检索 + 结构化提示 + 证据核对（DeepSeek） | 100% | 约 72%；判“支持”时精确率 0.90 |
| 纯程序 | 2.8% | 自动判定部分 85.2%（965 条） |
| 本地 NLI 小模型 | 100% | 39.5%，不可用 |

结论：大模型方法之间的差距在误差范围内（±7 个百分点）；纯程序对新闻句子几乎都转人工，但自动判了的部分可靠。CHEF 测不到数字、坐标、日期等结构化核查，这部分只在模拟数据上验证过，**没有在真实业务数据上验证**。
