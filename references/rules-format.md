# 审核规则的写法

规则有两个来源，**表格里每行自带的要求**优先被读入；`审核规则.xlsx` 里**明确填写**的项覆盖前者。

## 一、表格里每行自带的要求（自动读懂）

| 列 | 写法 | 变成的检查 |
|---|---|---|
| 字符要求 | `纯数字，6位` | 只能是数字，正好 6 个字符 |
| 字符要求 | `纯汉字，2~10个字` | 只能是汉字（含 ·），2 到 10 个字 |
| 字符要求 | `不超过50字` / `最多50字` / `≤50` | 字数上限 |
| 字符要求 | `至少2位` / `不少于2个字` / `≥2` | 字数下限 |
| 字符要求 | `经纬度` / `坐标` | 经纬度格式（度分秒、十进制度、“经度, 纬度”均可），并按坐标核对原文 |
| 字符要求 | `手机号` / `邮箱` / `身份证号` / `统一社会信用代码` / `邮政编码` / `字母和数字` / `纯字母` | 对应格式 |
| 数据要求 | `保留1位小数` / `填整数` | 小数位数 |
| 数据要求 | `单位：米` / `单位为平方公里` | 目标单位，资料里换了单位的数字会自动换算后比较 |
| 数据要求 | `不需要注明数据来源` | 这一行不核查出处 |
| 数据类型 | `数值` / `文本` / `日期` | 若这一列写的是类型而不是数据名，按类型处理 |

“纯数字”同时又有单位或小数要求时，按**数值**处理（允许小数点、按数值比较）；没有单位的纯数字按**编号**处理（如代码，逐字符检查）。

识别不了的写法会原样交给大模型（开启时）；没开模型就只做能识别的部分。

## 二、审核规则.xlsx

放在工作目录下，三张表，都可以直接用 Excel 改。

### 项目规则（按数据类型补充）

| 列 | 说明 |
|---|---|
| 填报项目 | 与表格“数据类型”列的值一致，如 `高度` |
| 必填 | 是 / 否 |
| 数据类型 | 数值 / 文本 / 日期 |
| 字符类型 | 下拉选择，同上表 |
| 字符数 | `6`、`2~10`、`≤50`、`≥2` |
| 单位 | 如 `米` |
| 取值范围 | `最小~最大`，如 `100~9000`，用来发现数量级或单位错误（超出只报“需复核”） |
| 小数位 | 数字 |
| 需核查出处 | 是 / 否 |
| 补充要求 | 一句话，交给大模型参考 |
| 正则表达式 | 高级：上面表达不了的固定格式，如 `QS-\d{4}` |

只写需要补充的列，空着的列不会覆盖表格里的要求。

### 通用规则

每行一条文字规则，适用于所有行，交给大模型参考（不开模型时不起作用）。

### 列设置

| 角色（不要改） | 填报表中的列名（多个别名用顿号分隔） |
|---|---|
| 项目 | 数据类型、填报项目、数据项 |
| 要求 | 数据要求、填写要求 |
| 字符 | 字符要求 |
| 内容 | 数据内容、填写内容 |
| 来源 | 数据来源、资料来源 |
| 日期 | 来源日期、来源发布日期 |

用户的表头不同（比如“指标名称”“填报值”）时，把它们加到对应角色的别名里。

## 三、对象名称行

`数据类型` 为 `名称`、`对象名称` 或 `名字` 的行，其内容就是后面各行的**核查对象**：审核“高度”时，程序只看资料里讲这个对象的段落（提到它的那一段及后面最多两段，遇到标题行或“某某位于/为/属……”开头的新对象段落就停）。
